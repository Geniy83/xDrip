# Отправка глюкозы в VK

xDrip может слать текущие показания CGM в личные сообщения VK через Community API `messages.send`.

## Настройка

1. Настройки → Загрузка в облако → **VK (vk.ru)**.
2. Включите «Отправлять глюкозу в VK».
3. Создайте сообщество VK, включите сообщения сообщества и получите ключ доступа с правом `messages`.
4. Укажите **числовые** ID получателей (user id или peer id). Каждый получатель должен **сначала написать сообществу**.
5. Выберите тип: текстовое сообщение или шаблон GlucoWatch.
6. При необходимости измените интервал, триггер и шаблон.
7. Нажмите «Отправить тестовое сообщение».

Токен сообщества не пишется в логи. Endpoint по умолчанию: `https://api.vk.com/method/messages.send`, версия API `5.199`.

## Токены шаблона

`{value}` `{unit}` `{trend_arrow}` `{time}` `{mgdl}` `{mmol}` `{raw}` `{status_emoji}` `{iob}` `{cob}` `{timestamp}` и другие — список в диалоге шаблона.
